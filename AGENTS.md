# Instructions for agents

This repository holds independent projects for a Garmin fenix 6X Pro. Each
folder has its own README. Nothing here needs a network service or an
account.

| Task | Read |
| --- | --- |
| Install the Cards widget on the watch and the Card Loader app on the phone | `card-wallet/AGENTS.md` |
| Install the vibration test app on the watch | `card-wallet/AGENTS.md`, section "The vibration test app", and `moto-nav/vibe-test/README.md` |
| Chinese reading support on the watch | `cn-characters-support/README.md` |

Rules that hold in every folder:

1. Ask the owner before every step that changes the watch or the phone, and
   change only the file that step names.
2. Never read, capture or print the owner's card codes or anything in a
   `private/` folder. Test with the sample data each project ships.
3. Commit or push nothing unless the owner tells you to. The repository is
   public: no personal names, no home-folder paths, no device serial numbers
   in any file or commit message.
