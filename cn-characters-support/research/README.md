# Research scripts

These are the scripts used to work out the file formats of the watch's fonts and
language files. They are not needed to use the project.
Some talk to the watch (`push_test.sh`, `push_extdata.sh`); use them only on a watch you have backed up.
Run them from the project folder. `replace_file.c` builds `bin/replace_file`, which they call.
Several need fonttools: `brew install fonttools`.
